# Allowed visual styles

Visual style controls rendering only. It does not change the specified topology, content, actions, or state.

## Minimalism

Use the fewest elements, deliberate negative space, a restricted palette, and one typographic emphasis.

## Claymorphism

Use independently colored inflated controls, oversized radii, two inner shadows, and one outer shadow.

## Liquid glass

Use glass only for floating controls and navigation above opaque content. Use capsule and concentric geometry.

## Glassmorphism

Use translucent frosted surfaces over a vivid backdrop, thin light borders, and layered depth.

## Neumorphism

Use one matte surface, matching control fills, dual soft shadows, and inset active or input states.

Sources: [Claymorphism](https://namethatui.com/styles/claymorphism), [Minimalism](https://namethatui.com/styles/minimalism), [Liquid Glass](https://namethatui.com/styles/liquid-glass), [Glassmorphism](https://namethatui.com/styles/glassmorphism), [Neumorphism](https://namethatui.com/styles/neumorphism).
