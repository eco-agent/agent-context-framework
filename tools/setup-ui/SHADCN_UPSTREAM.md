The project adapts the generated base-mira theme, utility helper, and Button,
Checkbox, Input, Alert, Badge, Skeleton, Spinner, Sidebar, Sheet, Tooltip,
Separator, and Accordion recipes. The application shell follows the upstream
`sidebar-07` block. ACF retains its existing Vite client, setup API, and
application state.

The sidebar integration changes generated imports to NodeNext-compatible
relative paths and caps sidebar separators at `calc(100% - 1rem)`. The latter
preserves the recipe's intended inset width after Tailwind expands the base
Separator recipe. Mobile sidebar DOM properties move to `SheetContent` because
the Base UI sheet root does not render an element for those properties.

The selected-file adoption lives in `src/components/ui`, `src/lib/utils.ts`,
`src/styles`, and `components.json`. It is not a subtree or a separate package.

## Update procedure

1. Generate the preset in a clean temporary directory with
   `pnpm dlx shadcn@4.19.0 init --preset byaZqBz6I --template start --pointer`.
2. Inspect the current block before updating local sources with
   `pnpm dlx shadcn@4.19.0 view sidebar-07`.
3. Add or refresh the adopted recipes in the clean preset with
   `pnpm dlx shadcn@4.19.0 add sidebar accordion separator`.
4. Compare the generated theme, block, utility helper, and adopted component
   recipes with their owned files in this package. Keep ACF's setup state and
   API code.
5. Update the pinned repository revision and package integrity only after the
   generated sources and MIT terms have been checked.
6. Run the setup UI typecheck and build, then review component selection, plan
   updates, the narrow-screen drawer, reduced motion, and the fixed action
   region.
