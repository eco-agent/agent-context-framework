# Frontend composition workflows

Revision `0.11.0` adds the optional `workflow-frontend-composition` component.

The component installs the generic representation and compose controllers from
`packages/codex-frontend-workflows` into ACF's isolated runtime. It also installs
the canonical workflow runtime and the frontend design and orchestration skills.
The ordinary `frontend` bundle does not select this component.

The controller package owns strict frontend specification bundles, bounded model
roles, content-addressed evidence, a zero-model preflight, and exact human
acceptance. It does not own repository operations. Each consumer supplies Git,
browser, package-manager, and fixture adapters through the compose environment
port.

Human acceptance binds the run to immutable specification or render evidence.
An exact replay succeeds without a second write. A stale target or conflicting
replay fails before the workflow can enter the accepted state.
