# Registry 0.9.1: explicit push authority

## Status

Accepted.

## Decision

Agents may push commits only when the user explicitly requests a push. Agents
may deploy only when the user explicitly requests a deployment. A request to
push does not authorize deployment, and a request to publish one branch does
not authorize publishing other branches or tags.

The canonical core instruction and root prefix own the rule. The root `AGENTS.md`
is their generated projection. Governance protects the exact authority and
deployment boundaries.

## Preservation map

| Behavior | Disposition |
| --- | --- |
| Checkpoint commits and branch isolation | Retained |
| No implicit push | Retained |
| Push after an explicit user request | Added |
| No implicit deployment | Retained and clarified |
| Preservation of unrelated changes | Retained |

## Boundary

- Owner: canonical core instruction and root prefix.
- Observation: governance checks source hashes, required phrases, and exact
  projection into `AGENTS.md`.
- Grace path: without an explicit request, keep commits local and report the
  unpublished branch.
