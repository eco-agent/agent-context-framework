# Registry 0.17.0 removes the default tw-fade dependency

Revision `0.17.0` stops the Tailwind policy and skill from requiring `tw-fade`.
Projects may still choose the package under their own frontend contract.

The canonical Tailwind instruction now requires only `shadow-plugin` after
`tailwindcss`. The Tailwind skill keeps its utility ownership, raw CSS
exceptions, import order, elevation rules, and verification requirements. It no
longer requires a fade class on every scrolling element.

The framework root and workspace lockfile no longer install `tw-fade`. The
dependency adoption record is removed because the framework has no remaining
tracked use for it. The setup UI was removed by revision `0.15.0`, so this
revision does not restore or modify that obsolete application.

The registry projection checks observe the instruction and skill changes. The
dependency-adoption check observes the package and adoption removal. Projects
that need scroll-edge fades may select `tw-fade` or a project-owned treatment
and record that choice in their own contract.
