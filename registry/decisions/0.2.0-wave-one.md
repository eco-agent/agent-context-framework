# Registry 0.2.0 — Wave 1 frontend discipline

## Decision

Replace the unpublished ownership-oriented v1 registry with provenance-oriented
v2 and package the first portable frontend context bundle.

## Affected invariants

- `core-project-ownership`
- `frontend-no-model-priors`
- `frontend-no-invented-product`
- `frontend-precedent-before-topology`
- `frontend-preserve-visible-copy`
- `frontend-assets-are-inputs`
- `frontend-state-once`
- `frontend-elevation-contract`
- `frontend-font-smoothing`
- `frontend-no-unrequested-style-system`

## Context fidelity

The Wave 1 frontend instruction source and every skill source are byte-for-byte
projections of the framework context at the decision baseline. This release
does not revise their meaning. It adds packaging, provenance, capability and
license declarations, cache exclusion, and anti-dilution verification only.

## Exclusions

- Tailwind generated cache metadata and screenshots
- Wave 2 engineering components
- Repository policy installation
- Codex agents, hooks, and repository-context runtime
- Objective orchestration
