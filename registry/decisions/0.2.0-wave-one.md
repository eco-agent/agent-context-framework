# Registry 0.2.0 — Wave 1 frontend discipline

## Decision

Replace the unpublished ownership-oriented v1 registry with provenance-oriented
v2 and package the first portable frontend context bundle.

## Affected invariants

- `portable-core`
- `frontend-discipline`
- `repository-work`
- `verification`
- `documentation-prose`
- `core-project-ownership`

## Context fidelity

The Wave 1 frontend instruction source and all protected instruction
projections are byte-for-byte copies of the framework context at the decision
baseline. This release adds packaging, provenance, capability and license
declarations, cache exclusion, and anti-dilution verification.

One skill change is necessary for the cache exclusion to remain valid. The
responsive CSS fallback now synchronizes its generated Tailwind documentation
cache from the retained manifest when that cache is absent. Its frontend
policy and design guidance are unchanged.

## Exclusions

- Tailwind generated cache metadata and screenshots
- Wave 2 engineering components
- Repository policy installation
- Codex agents, hooks, and repository-context runtime
- Objective orchestration
