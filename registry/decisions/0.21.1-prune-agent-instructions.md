# Project decision: put detailed guidance in task skills

## Status

Accepted

## Context

The root `AGENTS.md` loads on every task. It repeated the remote-branch workflow, carried the full imported Unslop checklist, and imposed detailed frontend rules on tasks that never touch a frontend. The user asked to reduce this load, use the installed Unslop skill, and remove the visualize and standalone HTML-export instructions.

## Decision

Keep the remote-work safety and ownership rules in the root instructions. Remove the duplicate branch preamble from the portable core. Remove the embedded Unslop checklist and its closing writing check. The installed `unslop` skill owns that guidance.

Remove the visualize recommendation and standalone HTML-export rule from the root prefix. Neither is a repository safety boundary.

Keep a short frontend router in `AGENTS.md`. Every frontend edit reads `references/frontend-baseline.md` through the short root instruction. The `frontend-design-discipline` skill still applies to substantial or unsettled design work. The reference retains the prior frontend implementation rules. The existing `tailwind-css-architect` skill owns Tailwind detail, so the root Tailwind section only routes to it when project policy selects Tailwind.

When a project has no approved design system, the frontend baseline now recommends Fluid Functionalism rather than a vague minimalism default. The reference uses the project's existing tokens and component primitives where possible and requires a recorded constraint when the system cannot be adopted. The source assessed for this decision is [mickadesign/fluid-functionalism](https://github.com/mickadesign/fluid-functionalism/tree/b3587bdbd83fc66c2a6aae3817ffb856cb09260b), MIT licensed.

## Preservation map

| Behavior | Result |
| --- | --- |
| Remote branch ownership, local checkout protection, human merge and deployment | Retained in the root prefix, core, and `github-workstreams` skill. |
| Detailed frontend implementation rules | Moved intact to a conditional skill reference. |
| Tailwind styling detail | Retained in `tailwind-css-architect`; root instructions now route to it. |
| Embedded Unslop checklist | Removed from root instructions; the installed `unslop` skill owns it. |
| Visualize and standalone HTML-export prompts | Removed at the user's request. |
| Registry projection and protected-source checks | Updated to match the new owners. |

## Verification

The registry, governance hashes, preserved-prefix hash, generated `AGENTS.md`, and instruction tests must agree. The user-owned local checkout remains untouched; GitHub checks, if available, provide execution evidence for the pull request head.
