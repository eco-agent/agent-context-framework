# Registry 0.19.0 permits implicit skill-authoring guidance

The `writing-great-skills` skill may now load when a request matches its catalog
description. Authors no longer need to name the skill explicitly before Codex
can use its pruning, structure, invocation metadata, and completion guidance.

The skill remains limited to creating or editing model-facing skill
instructions. Its body, dependency closure, and verification requirements do
not change. The catalog description remains the trigger, and the agent-prose
check observes changes to model-facing files.

The registry revision changes because repository status compares capsule and
manager registry revisions. Existing capsules must report `repack-required`
until they contain the new invocation metadata.
