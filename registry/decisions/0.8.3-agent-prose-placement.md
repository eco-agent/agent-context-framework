# Registry 0.8.3: agent prose placement

Registry `0.8.3` keeps the full Unslop instruction set unchanged and adds a
short reminder after the other checked-in framework instructions. It also
rewrites the three Codex role prompts in ordinary language. The component list
and its dependencies do not change.

## Decision

- Keep Unslop in the protected core source. Add a short writing check at the end
  of that source and at the end of this repository's `AGENTS.md` projection.
- State plainly that policy prose is not an example of the writing style agents
  should copy.
- Rewrite the default, scout, and worker prompts with concrete descriptions of
  their work. Preserve their scope, permissions, stopping conditions, and model
  settings.
- Put the same short reminder at the end of each role prompt. Managed workflow
  prompts also end with a reminder that applies to prose values without changing
  JSON keys or other machine-readable text.
- Replace abstract task-envelope labels with names that describe their contents.
  `Objective boundary`, `Delegation`, and `Input` become `Objective`, `Your
  assignment`, and `Task input`.

## Protected semantics

- `unslop-source-preserved`
- `policy-prose-is-not-output-style`
- `writing-reminder-after-framework-context`
- `plain-role-prompts`
- `role-scope-and-permissions-preserved`
- `machine-readable-output-preserved`

## Preserved boundaries

- The Unslop process and its 31 patterns do not change.
- Role models, reasoning effort, sandbox settings, and delegation permissions do
  not change.
- Objective limits, authority checks, thread handling, return schemas, and JSON
  decoding do not change.
- No component, dependency, capability, package manifest, lockfile, migration,
  publication, deployment, or push is added.
